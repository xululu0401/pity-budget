# 保底成本台（pity-budget）

把一条「基础概率 + 保底规则」还原成逐抽出货概率序列，算出达到目标所需的**抽数分布**：平均要花多少、一半人多少、九成人多少、最坏多少，以及在你给定的预算内能拿到的概率。

- 体验地址：https://xululu0401.github.io/pity-budget/
- 单文件应用：`index.html`（由 `template.html` + `core.js` + `ui.js` 经 `build.cjs` 拼成），无外部依赖、不联网。

## 算法

| 步骤 | 说明 |
|---|---|
| 1. 概率序列 | 硬保底：`p_k = p (k<N)`、`p_N = 1`；软保底：`p_k = min(p + max(0, k−s+1)·q, 100%)`，且第 N 抽强制 100% |
| 2. 逐抽 DP | 状态 = （已完成目标数 j，当前周期已抽次数 k）；每抽以 `p_k` 出货（出货后 k 归零），否则 `1−p_k` 未出 |
| 3. 抽数分布 | 逐抽累计得到 `F(t) = P(S_m ≤ t)`，`S_m` 为拿到 m 个目标所需抽数 |
| 4. 读结论 | 期望 `Σ t·P(S_m=t)`、分位数（最小 t 使 F(t) ≥ q）、预算达标概率 `F(⌊预算÷成本⌋)`、最坏上限 `m × N` |
| 5. 对照 | 同一基础概率下的「无保底」重新求解一次，用来量化保底砍掉的是期望还是尾部 |

闭式解（供互证）：无保底 `E[T] = 1/p`；硬保底 `E[T] = (1 − (1−p)^N)/p`。多目标 `E[S_m] = m·E[T]`。

## 边界

概率、保底规则、成本、目标数量与预算全部由用户填写；不提供任何平台的真实概率，不联网，不预测单次结果，不构成消费建议。规则假设每一抽在给定概率下独立、每次出货后保底计数重置、目标之间相互独立；不处理保底继承、十连折扣、首充礼包、货币档位与限时叠加。无保底口径下抽数没有上限（页面把尾巴截断在累计概率 `1 − 1e-15` 处）。默认样例与内置场景均为虚构示例。
